APPENDIX A — Installation and Setup Guide

The installation and setup process for the MoodAI system requires several hardware and software components to ensure smooth operation. To run the platform effectively, the user needs a computer with the Windows operating system and at least 8GB of random-access memory. A working webcam and a functional microphone are also necessary for the facial and voice emotion detection features. For software, the system requires XAMPP for managing the web server and the database, Python 3.12 for the artificial intelligence backend, and a modern web browser like Google Chrome or Mozilla Firefox to access the user interface.

The first step in the installation is to set up the XAMPP environment. The user should download the XAMPP installer from the official website and follow the setup instructions. Once the installation is complete, the XAMPP Control Panel should be opened to start the Apache and MySQL services. After starting these services, the entire PHP project folder must be copied and pasted into the htdocs directory, which is usually found within the XAMPP installation folder on the C drive. This allows the local server to recognise and serve the application files to the browser.

The next step involves importing the system database using phpMyAdmin. The user should open their web browser and navigate to the local host address for phpMyAdmin. A new database named movie_system must be created to hold the application data. Once the database is created, the user should select the import tab and choose the movie_system.sql file provided in the project folder. After the import process is finished, the user should confirm that all eight database tables, including users, admins, and history, have been successfully created and are ready for use.

After setting up the database, the Python requirements must be installed for the AI backend. The user needs to open the command prompt and navigate to the directory where the Python backend files are stored. By running the pip install command for the requirements text file, all the necessary libraries will be downloaded and installed. These libraries include Flask for the API, DeepFace for face detection, and Faster-Whisper for voice transcription. The user must wait for all these dependencies to install completely before proceeding to the next part of the setup.

The configuration of the system settings is the fifth step. The user should open the configuration file located in the includes folder of the PHP backend and provide the correct database credentials such as the host name, username, and password. It is also important to add a valid TMDB API key to the system so that movie data can be fetched from the internet. This key can be added through the settings page in the admin panel or by editing the configuration file directly. Proper configuration ensures that the frontend can communicate with both the local database and the external movie API.

The sixth step is to start the Python Flask server to enable the mood detection features. The user should open a separate command prompt window, navigate to the Python backend folder again, and run the main application file using the Python command. Once the server starts, it will listen for requests on port 5000. It is essential to keep this terminal window open at all times while using the system, as closing it will stop the AI services from working. The server provides the necessary routes for processing biometric data and returning the emotional state of the user.

Finally, the user can access the completed system through their web browser. By entering the correct local host URL for the project, the home page will load, and the user can choose to register a new account or log in using the guest feature. Once access is granted, the user can select any of the three mood detection methods to identify their current feelings. After the mood is detected, the system will suggest a list of movies that match the results. This final step confirms that all parts of the project are correctly installed and integrated.
